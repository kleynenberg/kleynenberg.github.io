2026 Preprint DOI: 10.13140/RG.2.2.15845.77289 WebGL 2 & Perturbation Theory

Monolithic PWA Architectures for Real-Time Fractal Rendering: Perturbation Theory and Sub-Pixel Temporal Filtering in WebGL 2

Authors: Steven Kleynenberg, Google Gemini • Date: November 25, 2026 • Canonical URL: https://steven.kleynenberg.com/papers/monolithic_pwa_architectures_for_real_time_fractal_rendering_perturbation_theory_and_sub_pixel_temporal_filtering_in_webgl_2.pdf

We present a zero-dependency, single-file Progressive Web App (PWA) architecture for interactive deep-zoom Mandelbrot set exploration in WebGL 2. By combining CPU-side arbitrary-precision reference orbit calculation with GPU-side float32 perturbation delta iteration (δn+1 = 2znδn + δn2 + δc), adaptive sub-pixel temporal accumulation, and deterministic palette synthesis, the system achieves real-time 60 fps rendering beyond IEEE-754 float32 precision limits inside a self-contained HTML artifact.
